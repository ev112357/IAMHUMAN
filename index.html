Security Architecture

Turing's Gate employs a multi-layered defense protocol to ensure all interactions originate from verified organic traffic.

1. Passive Telemetry Engine

While you write a post we look at a few simple behaviour signals: whether the text was pasted, an impossible typing speed, a hidden trap field that only bots fill in, and posting in rapid bursts. We never keep what you typed for this check, only a risk score from 0 to 5 on your profile (you can see it in Settings > Privacy). Reaching 5 pauses posting until you solve a short code.

2. Cryptographic Token Validation

Core database write-actions (account creation, login) are safeguarded by Cloudflare's invisible Turnstile verification, requiring cryptographic proof of humanity before communicating with our backend.

3. Secure Row-Level State (RLS)

Direct API spam is nullified. All backend tables strictly enforce Row Level Security, rejecting any insertions from unauthenticated, unverified connections.

4. Web of Trust & Sybil Mitigation

To prevent automated account farming, each verified human is granted strictly three non-renewable lifetime invites. Invites form a cryptographic chain of custody: vouching for bad actors or bot scripts directly degrades the inviter's Human Verification score, neutralizing coordinated spam swarms at the root.
